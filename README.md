**RLP** is a collateralized lending protocol on **Robinhood Chain**. Lock a whitelisted token as collateral, borrow **ETH** against it, and repay on your terms to reclaim it. Fully live on a **non-custodial web app** and a **Telegram bot**.

- 🔓 **Borrow** ETH against whitelisted collateral, over-collateralized and priced live
- ♻️ **Repay** principal + fee within a fixed term to get your collateral back
- ⚡ **Automated liquidation** across Uniswap V2 / V3 / V4 keeps the protocol solvent
- 📱 Use it from the **web app** or straight from **Telegram**
